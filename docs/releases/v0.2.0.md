# v0.2.0 — First public release

Typing Tutor IV Remake is a local browser reconstruction of the DOS programme. All typing, scoring, report and game logic runs in JavaScript; a small Python server serves the static files.

## Included

- Original-style 80×25 keyboard-driven menus, settings, Help and explicit save/discard.
- Adaptive lessons through 64 keyboard entries, fingering review and numeric keypad lessons.
- Practice, All-keys, Disk-file and keypad tests, plus Progress, Speed and Accuracy reports.
- Letter Invaders with Practice Keys/Full Keyboard, one/two players and global high-score tables.
- Development log, static evidence, extraction scripts and tests. Earlier prototype retained in the source repository only.

## Run

Download the source archive and extract it, or clone the repository. In its root, run:

~~~sh
python3 scripts/serve.py
~~~

Open http://127.0.0.1:8080 in Google Chrome. Save through Quit → Yes, save session to history. Progress stays in that browser; Export browser data downloads a backup. Stop the server with Ctrl+C.

## Verification and known limits

143 unit tests and eight installed-Chrome workflows pass. The three local DOS references and 1,588 retained evidence files match their recorded hashes. Public CI checks unit tests and retained evidence integrity; Chrome workflows run locally.

Native DOS runtime comparison and Safari verification remain open. Exact font/audio, complete onboarding, original history import, backup import and instructor features are unfinished. Recovery evidence and browser observations are distinguished throughout the documentation.

Original DOS files, local tools and browser/user save data are excluded from this release. Generated resources and retained analysis have original-program provenance; see [THIRD_PARTY.md](../../THIRD_PARTY.md). New implementation code is MIT licensed; historical content is separately identified in COPYING.md and THIRD_PARTY.md.

This is the first public release, retaining the project's existing v0.2.0 version. Next development stage: F6 fidelity comparison against a disposable DOS working copy.
